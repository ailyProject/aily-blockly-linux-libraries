# @aily-project/lib-core-loop

Standard Blockly loop blocks for Linux CPython projects.

Blocks (6): `controls_repeat_ext`, `controls_repeat`, `controls_whileUntil`, `controls_for`, `controls_forEach`, `controls_flow_statements`.

The package validates matching handlers on `globalThis.Python.forBlock` without changing them. Use `controls_repeat_ext` for a connected count expression or `controls_repeat` for a compact fixed numeric field.
