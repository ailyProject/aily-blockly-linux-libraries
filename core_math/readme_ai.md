# @aily-project/lib-core-math

Standard Blockly math blocks for Linux CPython projects.

Blocks (13): `math_number`, `math_arithmetic`, `math_single`, `math_trig`, `math_constant`, `math_number_property`, `math_round`, `math_on_list`, `math_modulo`, `math_constrain`, `math_random_int`, `math_random_float`, `math_atan2`.

The package validates matching handlers on `globalThis.Python.forBlock` and leaves the existing handler references unchanged.
